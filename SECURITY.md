# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in YukkiMusic-Cpp, please report it responsibly:

1. **Do not** disclose vulnerabilities in public GitHub issues or discussions.
2. Report the issue privately by emailing the maintainers or creating a Private Vulnerability Advisory on GitHub.
3. Include detailed steps to reproduce the issue, proof-of-concept payloads (if applicable), and affected component versions.

Maintainers will respond within 48 hours to confirm receipt and coordinate an advisory and patch release.
